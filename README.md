# Privacy Inspector

Extensão Firefox desenvolvida para a Avaliação Intermediária
da disciplina de Cibersegurança do Insper.

## Objetivo

Detectar e apresentar comportamentos relacionados a privacidade
e segurança em páginas web, incluindo:

- conexões a domínios de terceira parte;
- cookies;
- armazenamento HTML5;
- canvas fingerprinting;
- bounce tracking e cookie synchronization;
- indicadores de browser hijacking/hooking;
- privacy score;
- bloqueio personalizado.

## Execução

1. Abra o Firefox.
2. Acesse `about:debugging`.
3. Escolha "This Firefox".
4. Clique em "Load Temporary Add-on".
5. Selecione `extension/manifest.json`.
